## Critical gotchas (learned the hard way)

1. **Never add a docker `healthcheck` to the `lobechat` service** — Traefik docker provider filters out containers reporting `health: starting` and never re-scans on health change. Logs will say `Filtering unhealthy or starting container`. Container with no healthcheck = Traefik treats it available immediately, which is what we want.

2. **Use full container hostnames inside compose env vars** — Docker DNS collides bare names like `redis` with Coolify's own internal containers (Coolify runs its own `coolify-redis` with a password). Always use `redis-<service-uuid>` form. (We use the bare names in this compose because Coolify's compose-application puts each service on an isolated network — but if you build a flat compose service, this bites you.)

3. **`APP_URL` must NOT include `:3210`** port suffix — Traefik forwards on 443; lobe does Host-header validation. Use the no-port URL.

4. **Better Auth removed NextAuth in v2** — do NOT set `NEXTAUTH_URL` or `NEXT_AUTH_SECRET`. They throw a startup error: `NextAuth has been removed from LobeChat. Please migrate to Better Auth.`

5. **`connect_to_docker_network: true`** must be enabled on the Coolify application — without it, Traefik can't see the per-service network (returns 503 "no available server"). Set via API:
   ```
   curl -X PATCH -H "Authorization: Bearer ${COOLIFY_TOKEN}" \
     "https://dash.chipone.ai/api/v1/applications/j10ip3rcpokqyfm2l1jjmxta" \
     -d '{"connect_to_docker_network":true}'
   ```

6. **`rustfs-init` exits 0 = correct.** It's a one-shot bucket-creation job. Don't restart it.

## Decryption helper for stored API keys

User-set API keys are stored encrypted in `ai_providers.key_vaults` (AES-256-GCM with `KEY_VAULTS_SECRET`). To decrypt for backup/audit:

```js
const crypto = require('crypto');
const SECRET_B64 = '/phENztKOYPp72uAuhxsw0p5SFjqKQXGmt8OjLcSdNc=';
const key = Buffer.from(SECRET_B64, 'base64');
function decrypt(s) {
  const [ivHex, tagHex, ctHex] = s.split(':');
  const iv = Buffer.from(ivHex, 'hex');
  const tag = Buffer.from(tagHex, 'hex');
  const ct = Buffer.from(ctHex, 'hex');
  const d = crypto.createDecipheriv('aes-256-gcm', key, iv);
  d.setAuthTag(tag);
  return Buffer.concat([d.update(ct), d.final()]).toString('utf8');
}
```
